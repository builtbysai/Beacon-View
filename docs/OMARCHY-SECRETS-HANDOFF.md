# Omarchy secrets handoff

No values belong in this document or in Git. The authoritative backend schema is `apps/backend/src/config.ts`; examples are `apps/backend/.env.example` and `infrastructure/cloud/production.env.example`. Windows `apps/backend/.env` currently contains only the 19 basic local-development names from its example; the optional provider and encryption names below are absent there. Check the private production host or the owner's credential store separately before retiring access to either.

`Required locally` means the normal loopback development workflow. Optional integrations require their complete field group when enabled. Transfer sensitive values through an owner-selected encrypted channel or recreate them at their provider. Never place them in the ordinary handoff ZIP or Git bundle.
