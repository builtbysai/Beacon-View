# UI and UX roadmap

The single actionable plan is now [roadmap.md](roadmap.md#uiux-completion--current-approved-batch).
See U1–U4 for current UI work, N1/N2/N8/N9 for acceptance, and the deferred table
for features that need approval. This file no longer maintains a second delivery sequence.

The [design decision](decisions/0033-trust-first-design-system-adoption.md) remains
the visual and accessibility contract: Paper/Evening, visible capture and privacy,
explicit Listen/Talk, status text plus glyphs, responsive window-based layouts,
large targets, keyboard focus, and honest capability/error states.

Native Monitor stays single-camera until a separately approved milestone follows
device capacity measurements. Web multi-camera layouts already exist; their
capacity and physical media acceptance must not be inferred from visual QA.
