## Lessons

- Text written through `node -e` or a shell heredoc loses backslashes. Write patch scripts with a file tool, grep the
  diff for regexes, and give every parser a test that feeds the real production value. One lost backslash crash-looped
  the first deploy (rolled back in minutes).
- Run `prettier --check .` for the whole repository before pushing, like CI does.
- Deploy with a database dump, rollback tags and a health check that rolls back on its own.
