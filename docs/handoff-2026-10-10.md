  `/opt/beacon/releases/web-f941373c6f0327b6518bdedfc6ef276e4eba1dc5`;

## Things to know

- **coturn on the VM is not what the repository describes.** It runs
  `coturn/coturn:4.13.0` with the config mounted from `/opt/beacon/app/...` and
  Beacon Remote's relay entrypoint, so it is shared with Remote. This release left it
  alone. The new private-peer denial and quotas in `infrastructure/cloud/turnserver.conf`
  are therefore **not live**; apply them to the mounted file and recreate coturn only
  with Remote's owner in mind, then run the relay smoke test.
- **Android Google sign-in now needs PKCE.** The installed Android app must be
  updated (a new build) before Google sign-in works on it. Password sign-in is unaffected.
- **Desktop app:** the confirmation before camera enrollment lives in the Electron app,
  so it ships only with a new desktop release (not yet built or published). The web
  viewer changes are live for the installed app already.
- The backend now runs as `node` (uid 1000). A Firebase credential file, if mounted
  later, must be readable by that uid.
- Content-Security-Policy is report-only: check the browser console through sign-in,
  live view, Camera Mode, Cast and recordings, then rename the header to enforce it.
- The deploy workflow now runs only when the repository variable `BEACON_AUTO_DEPLOY`
  is `true`.
