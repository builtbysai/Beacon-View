# Repository instructions

This repository contains Beacon View, an Android-first system that turns an
unused Android phone into a remotely accessible security camera.

## Priorities

1. Security and privacy
2. Correctness
3. Simple consumer setup
4. Reliability on unstable networks
5. Cost-efficient architecture
6. Maintainability

## Working rules

- Work on one milestone at a time.
- Do not begin later milestones without explicit approval.
- Run all relevant tests before presenting a change.
- Never commit secrets.
- Do not weaken security controls to make tests pass.
- Record significant architecture decisions under docs/decisions.
- Keep the README and local-development documentation current.
- Prefer mature dependencies.
- Flag legal, privacy, security, and recurring-cost decisions for human review.
